# lifepayment · 轻账

轻账是 YaKit 系列的本地记账应用，帮助你在 Windows 和 Android 上记录个人收支、查看花销并管理共同账本。

[快速使用](#快速使用) · [工程说明](Public.md)

## 功能特性

- 手动记账，或用一句话描述交易，核对金额、时间和付款账户后保存。
- 搜索、修改账单并查看修改历史，从回收站恢复误删的个人记录。
- 按日期、分类和付款人查看收支，分别统计人民币、日元、美元和欧元。
- 导入、导出 CSV 或 JSON 账单，核对疑似重复记录和缺失信息。
- 添加付款账户，设置商户对应的分类规则。
- 选择账单加入共同账本，在“我的 / 我们”之间切换查看。
- 将账本加密保存在本机，创建带恢复密码的备份。
- 连接自己的 WebDAV 存储空间，与已配对设备同步账本。
- 在支持的 Windows 安装版本中核对截图、选取通知录入账单，并使用 Windows Hello 锁定账本界面。

## 安装方法

当前版本为 **0.1.0 开发版**。提前体验可从 GitHub 的构建记录中下载测试包，正式版本请查看 [Releases 发布页](https://github.com/git-yafaya/YaKit-lifepayment/releases)。平台要求和可用功能见下方[兼容性](#兼容性)。

1. 登录 GitHub，打开 [Windows 测试包下载入口](https://github.com/git-yafaya/YaKit-lifepayment/actions/workflows/windows.yml) 或 [Android 测试包下载入口](https://github.com/git-yafaya/YaKit-lifepayment/actions/workflows/android.yml)。
2. 选择 `main` 分支最近一次带绿色对勾的成功记录。
3. 在页面的 **Artifacts（构建产物）** 区域下载对应压缩包。
4. 解压后，Windows 双击 `.exe` 安装；Android 将 `.apk` 传到手机，点击文件并按系统提示允许该来源安装。
5. 打开“轻账”，按下面的快速使用步骤记下第一笔。

| 平台 | 下载名称 | 解压后的文件 |
| --- | --- | --- |
| Windows | `LightLedger-Windows-x64` | `.exe` 安装程序 |
| Android | `LightLedger-Android-arm64-debug` | `.apk` 测试安装包 |

如果没有成功记录，或下载文件已过期，请等待下一次成功构建。当前 Android 安装运行、Windows 安装与系统功能，以及两端同步效果仍待实机验证。

## 使用说明

### 快速使用

安装后，你可以记下一笔支出，并立即在“账单”中看到它。**首次使用需要先添加付款账户。**

1. 按上方安装方法安装对应平台的测试包并打开“轻账”。
2. 进入“设置 → 付款账户 → 添加账户”，填写“现金”或你常用的付款账户名称。
3. 回到首页，点击“记一笔”。
4. 输入金额和发生时间，选择类型、币种、付款账户与付款人，点击“保存账单”。
5. 打开“账单”查看刚保存的记录，或进入“分析”查看收支。

### 记录、查找和恢复账单

1. 点击“记一笔”填写交易，或在首页点击“说一句，记一笔”，输入“午饭支出 28 元”后点击“识别并补充”。
2. 核对类型、币种、金额、发生时间、付款账户与付款人，按需填写商户、分类和备注，再点击“保存账单”。
3. 记录退款时，先打开原支出的详情复制账单编号，再填写到退款表单的“关联原账单”中；退款币种须与原支出相同，累计退款不能超过原金额。
4. 在“账单”中输入商户、分类或备注，按需选择日期后点击“搜索”。
5. 打开一条记录，点击“编辑”修改内容，或展开“修改历史”查看变更。
6. 在“我的”范围内点击“移到回收站”删除记录；需要恢复时，进入“回收站”打开该记录并点击“恢复账单”。

### 查看收支分析

1. 通过顶部“我的 / 我们”选择个人账单或共同账单。
2. 进入“分析”，选择开始与结束日期，点击“查看分析”。
3. 查看各币种的收入、净支出，以及每月、分类和付款人支出。

净支出会扣除关联退款，转账不计入收支；不同币种分别展示，不自动换算汇总。转账目前只记录流水，不调整两个账户的余额。

### 导入、导出账单

目前支持与轻账导出格式一致的 CSV 或 JSON 文件；第三方应用导出的账单需要先按该格式整理，并核对日期、金额单位和付款信息。

1. 在“设置 → 账本与备份”点击“导出 CSV”或“导出 JSON”，选择保存位置，可将导出的文件作为格式参考。
2. 在首页点击“导入账单”，选择准备好的文件。
3. 核对内容预览，点击“开始导入”，查看新增、已存在、待确认和失败的数量。
4. 按提示修正失败行，到“待处理”核对疑似重复或补充缺失信息，再到“账单”查看结果。

重复导入同一文件会识别已有来源；失败行不会阻止其他有效行导入。CSV 和 JSON 是未加密的账单文件，需要加密保存时使用“加密备份”。

### 处理待确认事项

1. 进入“待处理”，展开对应事项的“查看原始记录”，核对关联内容。
2. 对疑似重复记录选择“合并为同一笔”或“保留为新交易”；对缺少信息的记录点击“核对并处理”并补齐内容。
3. 对共同账本申请选择“同意申请”或“拒绝申请”；遇到同一项内容不一致时，逐项选择保留本机内容或采用新值并保存。

### 管理付款账户与分类规则

1. 在“设置 → 付款账户”点击“添加账户”，填写你要使用的账户名称。
2. 在“设置 → 分类规则”点击“添加规则”，填写商户名称及对应分类并确认。
3. 不再使用某条规则时，点击该规则旁的“撤销规则”。

### 在自己的设备之间同步

WebDAV 是你自行提供的在线文件存储空间；首次同步前，需要在两台设备上配置同一存储位置，具体填写方法见[配置说明](#配置说明)。以下操作均从“设置 → 设备与同步 → 设备配对”进入。

1. 在旧设备选择“第一步：导出本机个人账本信息”，保存文件并交给新设备。
2. 在新设备选择“新个人设备：读取旧设备信息并生成请求”，读取该文件，将生成的请求文件交回旧设备。
3. 在旧设备选择“可信设备：读取并批准加入请求”，选择个人账本，核对并填写新设备的指纹后读取请求并保存批准文件。
4. 在新设备选择“新设备：读取批准文件，完成加入”，核对并填写旧设备的指纹后读取批准文件。
5. 在两台设备的“设置”中点击“立即同步”，查看同步结果。

设备指纹是配对窗口中用于核对设备身份的一串字符，可展开“本机指纹与技术信息”查看。

### 使用共同账本

1. 在“设置 → 设备与同步 → 设备配对”中选择“创建我们的共同账本”，点击“继续”。
2. 请共同成员配置同一 WebDAV 存储位置，并在其设备的配对窗口选择“共同成员：生成加入请求”，将请求文件交给你。
3. 在你的配对窗口选择“可信设备：读取并批准加入请求”，选中共同账本，核对并填写对方设备指纹后读取请求并保存批准文件。
4. 请对方选择“新设备：读取批准文件，完成加入”，核对并填写你的设备指纹后读取批准文件。
5. 在“我的 → 账单”中打开要共享的记录，点击“加入共同账本”，双方同步后切换到“我们”查看。
6. 在“待处理”中核对共同账本的修改与删除申请。

共同账本只展示主动加入的记录。在“我的”中删除已共享账单，不会删除共同账本中的那份记录；需要共同删除时，在“我们”的账单详情中点击“申请共同删除”。共同删除后，个人恢复不会自动重新共享。

### 备份与恢复

1. 进入“设置 → 账本与备份”，点击“加密备份”并选择保存位置。
2. 设置至少 8 个字符的恢复密码并确认，保存好备份文件和密码。
3. 需要恢复时，先备份当前账本，再点击“恢复备份”，选择备份文件并输入对应恢复密码。
4. 恢复完成后核对账单；需要继续同步时，重新完成设备配对。

### 使用 Windows 截图、通知和应用锁

截图与通知录入需要 MSIX 安装版本；上方下载入口中的 `.exe` 安装包不提供这两项能力。截图识别还需要本机中文识别组件，可用状态和原因会显示在“设置 → 隐私与自动录入”中。

1. 录入截图时，在首页点击“导入截图”，选择图片，核对识别文字后点击“继续确认账单”，补齐信息并保存。
2. 录入通知时，在“设置 → 隐私与自动录入”点击“授权与选择来源”，允许访问并选择应用，再点击“保存选择并读取”。
3. 从读取结果中选择要录入的通知，点击“核对账单”，补齐信息并保存。
4. 开启应用锁前，先在 Windows 设置中配置 PIN 或 Windows Hello，再在轻账中点击“开启应用锁”并完成身份验证；之后可点击“立即锁定”，或在下次打开时验证解锁。

通知只在你主动读取时获取所选应用的现有通知，每笔账单仍需确认后保存。

## 配置说明

本地记账和文字识别不需要大模型 API 密钥；只在使用同步、备份或应用锁时配置相应项目。

| 配置项 | 何时需要 | 填写或设置方法 |
| --- | --- | --- |
| 付款账户 | 首次记账前 | 在“设置 → 付款账户”添加，例如“现金”或“银行卡” |
| WebDAV 服务地址 | 设备同步前 | 填写存储服务提供的 HTTPS 地址，需要同步的设备使用同一存储位置 |
| WebDAV 用户名、密码 | 设备同步前 | 填写存储服务的登录信息，点击“测试并保存”；通过目录读取、写入、读取文件和清理测试后才会保存 |
| 恢复密码 | 创建或恢复加密备份时 | 创建时设置至少 8 个字符，恢复时输入同一密码；它与 WebDAV 密码用途不同 |
| 通知来源 | Windows 通知录入前 | 授权后勾选允许读取的应用，可选来源来自当前通知中心 |
| 应用锁 | 需要锁定账本界面时 | 默认关闭，在支持 Windows Hello 的设备上验证身份后开启 |

## 兼容性

| 平台 | 最低要求 | 要求来源与功能范围 |
| --- | --- | --- |
| Windows | Windows 11，64 位（x64），需要 WebView2 Runtime | 当前 Windows 包面向 x64，系统功能所需的 MSIX 包最低系统设为 Windows 11；WebView2 用于显示应用页面 |
| Android | Android 7.0（API 24）及以上，64 位 ARM（ARM64）设备 | 安装包最低版本设为 API 24，当前仅提供 ARM64 测试包；请保持系统 WebView 更新，截图识别、通知录入和应用锁暂不可用 |
| Linux / iOS | 暂无原生安装包 | 当前无法按上述方式安装使用 |

Windows 和 Android 的运行及同步验证状态见[工程说明](Public.md#当前接入状态)。

## 常见问题（FAQ）

### 断网还能记账吗？

可以，账本保存在本机。WebDAV 用于设备之间同步，断网不影响本地记账。

### 关闭应用后还会同步吗？

Windows 关闭窗口后应用退出，不再同步。Android 在应用进程存活时尝试同步，系统结束进程后停止；应用运行期间约每分钟尝试一次，也可以点击“立即同步”。

### 卸载应用或换手机前要做什么？

先创建加密备份并保存到应用之外的位置，同时保留恢复密码。Android 卸载会删除本机账本，系统备份和换机迁移不包含这些记录。

### 同步可以代替备份吗？

同步会传播账本变更，加密备份可以保留某个时点的账本；误删、损坏或更换设备时，应使用事先保存的备份恢复。

### 为什么付款账户列表是空的？

首次使用尚未添加账户，请到“设置 → 付款账户 → 添加账户”填写名称，再返回记账。

### 为什么截图或通知按钮不可用？

Android 暂未提供这两项功能；Windows 需要 MSIX 安装版本，截图识别还需要本机中文识别组件。打开“设置 → 隐私与自动录入”查看原因；通知列表为空时，请等待目标应用产生通知后再读取。
